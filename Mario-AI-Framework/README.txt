================================================================================
                       MARIO AI FRAMEWORK FOLDER
================================================================================
This folder hosts the Java 17 game engine and Robin Baumgarten A* pathfinding search agent.

KEY COMPONENTS:
- PlayLevel.java: Java Swing entry point executing human interactive play and AI playback.
- src/: Java source files including game physics, sprites, world state, and A* tree solver.
- bin/: Compiled Java .class files for the game engine and agents.
